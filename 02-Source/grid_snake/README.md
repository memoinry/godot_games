# Grid Snake

**作者：memory**

使用 Godot 4.4.1 或兼容的 Godot 4.4+ 标准版导入本目录的 `project.godot`，按 F5 开始。

主菜单的 HOW TO PLAY 提供全部操作。P / Esc 暂停，R 重开，M 静音，F11 全屏。最高分保存在本机用户数据目录 `memory_GridSnake/record.cfg`。

独立编写游戏逻辑与程序绘制图形；经典玩法练习项目。项目使用 AI 辅助编写与测试。Godot 引擎 MIT 许可见仓库 `THIRD_PARTY.md`。

测试：`godot --headless --path . --script res://tests/run_tests.gd`
